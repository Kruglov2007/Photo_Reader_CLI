# 📖 CLI Text Reader (OCR)

Простой и быстрый консольный считыватель текста с изображений на базе **Tesseract OCR** и **OpenCV**. Программа автоматически распознает печатный текст на русском и английском языках, выводит результат в терминал и сохраняет его в текстовый файл.

## ✨ Особенности
*   🚀 **Высокая скорость работы** — текст извлекается напрямую без отрисовки тяжелой графики.
*   🌍 **Двуязычность** — одновременное распознавание русского и английского языков (`rus+eng`).
*   💾 **Автосохранение** — результат автоматически записывается в файл `result.txt` с кодировкой UTF-8.

## 🛠 Требования и установка

### 1. Установка Tesseract OCR (для Windows)
Программа требует наличия установленного движка Tesseract в операционной системе. Откройте **PowerShell от имени администратора** и выполните команду:
```powershell
winget install UB-Mannheim.TesseractOCR
```

> ⚠️ **Важно:** По умолчанию установщик скачивает только английский язык. Чтобы программа читала по-русски, скачайте файл языковой модели [rus.traineddata](https://github.com) (около 19 МБ) и положите его в папку:  
> `C:\Program Files\Tesseract-OCR\tessdata\`

### 2. Установка зависимостей Python
Склонируйте репозиторий и установите необходимые библиотеки из файла зависимостей:
```bash
pip install -r requirements.txt
```
*(Вам понадобятся пакеты `pytesseract` и `opencv-python`).*

## 🚀 Запуск программы

1. Положите ваше изображение в папку проекта по пути `./images/img.png` (или укажите свой путь в коде).
2. Запустите скрипт:
```bash
python main.py
```
3. Распознанный текст отобразится в консоли, а рядом появится файл `result.txt` со всем содержимым.
